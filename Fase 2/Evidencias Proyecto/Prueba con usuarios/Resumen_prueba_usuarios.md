# Prueba con usuarios: Fase 3

El 10 de noviembre de 2026, 6 personas (5 con nivel de inglés intermedio y 1 avanzado) probaron la aplicación con cinco tareas y luego respondieron un formulario con el cuestionario SUS (System Usability Scale). Las respuestas originales están en `Respuestas_prueba_usuarios.xlsx`.

## Resultados

| Indicador | Resultado |
| --- | --- |
| Puntaje SUS promedio | **83,75 de 100** (mediana 78,75; mínimo 72,5; máximo 100). Sobre 80 se considera excelente. |
| Tareas completadas | **25 de 30** |
| Usarían la app para estudiar con compañeros de su nivel | **6 de 6** |
| El nivel del diagnóstico les pareció acorde a su nivel real | 5 de 6 |

| Tarea | Completada por |
| --- | --- |
| Registrarse e iniciar sesión | 5 de 6 |
| Rendir la evaluación diagnóstica | 5 de 6 |
| Crear un grupo o unirse con código | 6 de 6 |
| Proponer o confirmar un encuentro | 5 de 6 |
| Resolver un test semanal | 4 de 6 |

Nota: el formulario repitió por error la pregunta 4 del SUS. Las dos columnas tienen las mismas respuestas, por lo que el puntaje se calculó con una sola.

## Hallazgos y mejoras

| Hallazgo | Acción |
| --- | --- |
| Un participante obtuvo un error desconocido al resolver un test semanal | Reproducir y corregir el defecto; agregar una prueba |
| Los tests mezclan español e inglés | Unificar el idioma de los textos de los tests |
| La pantalla de encuentros no muestra la barra de desplazamiento | Habilitar el scroll en la lista de encuentros |
| Algunas pantallas se desajustan al cambiar el zoom del navegador | Revisar el diseño responsivo de la versión web |
| El test semanal no indica qué habilidades evalúa, aunque el resultado sí las desglosa | Mostrar las habilidades evaluadas al iniciar el test |
| A un participante le costó crear un grupo por timidez | Destacar los grupos abiertos para unirse sin tener que crear uno |
